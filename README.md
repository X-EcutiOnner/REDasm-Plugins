# REDasm Command Plugins
This repository contains plugin-callable commands for the **[REDasm Core Engine](https://github.com/redasm-dev/core)**.

Command plugins are very similar to [Analyzer Plugins](https://github.com/redasm-dev/analyzers), but they cannot work on its own and needs explicitely provided arguments.

## Current Commands
*   **COFF Parser (`coff_parse`)**: Iterates, dumps, and maps Common Object File Format structures.
